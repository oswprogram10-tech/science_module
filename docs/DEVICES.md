# 기준 기기 (초안)

> **초안이다.** 국내 학교 보급 기기 유형을 기준으로 정했다. 학교·교육청의 실제 보유 기기 목록이 나오면 그 목록으로 바꾼다. (결정 D8, `DEVELOPMENT_PLAN.md` §1)

근거: D1(Capacitor 앱: Android, 크롬북·Windows는 PWA. iPadOS 앱은 2026-11-09에 취소해 iPad는 Safari 웹판으로만 쓰고 실물 블루투스 센서는 쓸 수 없음), D2(성능 KPI), §4.2 ⑦(저사양 폴백), §7.0(스파이크 S1·S3).

## 등급

| 등급 | 뜻 | 대표 기기 유형(예) | 이 등급에서 켜는 기능 |
|---|---|---|---|
| A | 여유 | iPad Air(M1 이상), 갤럭시 탭 S 시리즈(최근 3년), 메모리 8 GB 이상 크롬북 | 모든 기능. 미시 화면 알갱이 최대치, 향후 3B급 튜터 모델 |
| B | 기준 | 보급형 iPad(9·10세대), 갤럭시 탭 S FE·중급형, 메모리 4~8 GB 크롬북·웨일북 | 모든 기능, 알갱이 수 70%. 향후 1B급 튜터 모델 |
| C | 저사양 | 보급형 안드로이드 태블릿(메모리 3~4 GB), 오래된 크롬북 | 알갱이 수 40%, 장식 애니메이션 끔. 향후 튜터는 규칙 기반만 |

웨일북(네이버 웨일 OS)은 크롬 계열이라 PWA와 Web Bluetooth를 크롬북과 같이 다룬다고 가정한다. **실기기 확인 필요.**

## 등급 판정

코드: `apps/student/src/platform/deviceTier.ts`의 `classifyDevice(signals)`.

입력 신호: `memoryGb`(`navigator.deviceMemory`), `cores`(`navigator.hardwareConcurrency`), `webgpu`(`'gpu' in navigator`), `platform`(`Capacitor.getPlatform()`), `reducedMotion`.

| 조건 | 등급 |
|---|---|
| 메모리 ≤ 4 GB 또는 코어 ≤ 4 | C |
| 메모리 ≥ 8 GB 그리고 코어 ≥ 8 | A |
| 그 밖 | B |
| 신호가 없음 | B |

- `reducedMotion`은 등급을 바꾸지 않고 판정 이유(`reasons`)에만 남긴다.
- iOS 웹뷰는 `deviceMemory`가 없으므로 메모리 신호 없이 코어 수만으로 판정한다. 코어가 4개 이하가 아니면 B가 된다(초안).
- 브라우저는 `deviceMemory`를 최대 8로 올림·내림해 알려 준다. 8 GB 이상은 모두 8로 보인다.
- `?tier=A|B|C`로 강제할 수 있다(테스트·시연용). `?dev=1` 패널에 "기기 등급 B (메모리 4 GB, 코어 8)"처럼 보인다.

### 이번 버전에서 등급이 바꾸는 것

미시 화면 알갱이 수 상한에 배율(A 1, B 0.7, C 0.4)을 곱한다.

- 적용: 용해 알갱이(녹은·녹지 않은), 기체 주사기 알갱이, 촛불 집기병 알갱이(전체와 처음 산소 알갱이 수에 같이 곱해 산소 비율을 지킨다).
- 적용하지 않음: 돋보기 모자이크처럼 실제 크기를 뜻하는 그림.
- 장식 애니메이션 끄기, 튜터 모델 선택은 다음 버전이다.

## 측정 대상 KPI (D2, 실기기에서 측정)

| KPI | 기준 |
|---|---|
| 시뮬레이션 렌더링 | 60 fps (기준 B) |
| 비전 추론 | 초당 5회 이상 |
| 안전 경고 지연 | 1초 이내 |
| BLE 페어링~첫 데이터 | 1.5초 이내 |

## 측정 절차 (초안)

1. 등급별 대표 기기를 한 대씩 구한다(A·B·C).
2. 단원별 E2E 흐름(`docs/testing.md`)을 실기기에서 직접 돌리며 프레임 시간을 기록한다.
3. 안전 경고는 `?dev=1`의 모의 안전 상황 버튼으로 일으켜 화면에 뜰 때까지의 시간을 잰다.
4. BLE는 `docs/app-packaging.md`의 시험 방법으로 연결 버튼을 누른 때부터 첫 값이 보일 때까지 잰다.
5. 결과를 이 문서에 표로 덧붙이고, 등급 경계(메모리·코어)가 맞는지 다시 본다.

`?dev=1` 패널에 측정값을 보여 주는 것은 다음 버전이다.
