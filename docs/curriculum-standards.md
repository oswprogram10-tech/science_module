# 성취기준 대조표 (2022 개정 과학과 교육과정)

- **출처**: 교육부 고시 제2022-33호 [별책 9] 「과학과 교육과정」(사용자가 준 원문 PDF, 2026-11-10 대조)
- 초등 성취기준은 모두 102개이다.
  - 3~4학년군은 `[4과01]`~`[4과16]`, 5~6학년군은 `[6과01]`~`[6과16]`이다.
  - 원문은 학년군만 정하고, 몇 학년에서 배우는지는 정하지 않는다.
- 앱 단원의 `standards`(매니페스트)는 아래 표를 따른다. 한 단원이 여러 성취기준에 걸리면 모두 적는다.
- 이전 값은 명세서의 단원 번호로 짐작한 "추정"이었고, 27개 단원이 틀렸었다. 원문에 없는 번호도 있었다(4과17, 6과18, 6과19, 6과10-04).
- `docs/specs/*-mvp.md`에 남은 옛 코드는 기록일 뿐이다. 현재 값은 이 문서와 매니페스트이다.

## 원문과 단원 구성이 어긋나는 것 (결정 필요)

1. **「지구와 바다」** (해결: 흐르는 물 실험은 땅의 변화로 옮기고, 지구와 바다는 원문 내용으로 새로 만듦. 활동 2도 만듦)
   - 앱의 흐르는 물 실험은 원문에서 「땅의 변화」(4과11-01)에 속한다. 2026-11-10에 3학년 「지구와 바다」(g3-earth-sea)에서 4학년 「땅의 변화」(g4-land)의 두 번째 활동으로 옮겼다(`docs/specs/stream-table-to-g4-land.md`).
   - 원문의 「지구와 바다」(4과06)는 육지와 바다 비교, 바닷물, 밀물과 썰물·갯벌이다. 단원 id `g3-earth-sea`를 다시 써서 이 내용으로 새로 만들었다. 활동 1 「바닷물과 강물 비교하기」(4과06-02, 물의 종류·물의 양·접시 모양 → 남은 하얀 가루와 마른 시간)는 `docs/specs/g3-earth-sea-v2.md`이다.
   - 활동 2 「밀물과 썰물 관찰하기」(4과06-03)는 이 단원의 두 번째 활동으로 덧붙였고 standards에 4과06-03을 더했다(관찰 활동: 시각 슬라이더로 옆에서 본 바닷가의 바닷물 높이·갯벌, 하루 그래프. `docs/specs/g3-earth-sea-tide-ext.md`). 원문의 "갯벌의 가치와 보전을 설득·홍보"는 활동 끝 생각 질문으로 열어 둘 뿐 따로 평가하지 않는다.
2. **달 모양 변화** (해결: 4학년으로 옮김)
   - 원문은 달의 위상 변화를 3~4학년 「밤하늘 관찰」(4과13-01)에 둔다.
   - 6학년 「지구의 운동」(6과12)에는 달이 없다.
   - 해결: 2026-11-10에 달 모양 과제 둘(`moon-change`, `full-moon`)을 4학년 「밤하늘 관찰」로 옮겼다(`docs/specs/moon-to-g4-night-sky.md`). 6학년 「지구의 운동」은 달 과제를 넣기 전으로 돌아갔다.
3. **「날씨와 우리 생활」(g5-weather)** (해결: 원문 6과06-02를 직접 다루는 두 번째 활동을 덧붙임)
   - 해륙풍 실험(활동 1)에 딱 맞는 성취기준은 없다. 기압 차이와 바람을 다루는 6과06-03이 가장 가까워 그대로 둔다.
   - 원문 6과06-02 "이슬, 안개, 구름을 관찰하고, 공통점과 차이점을 찾을 수 있다."를 다루는 활동 2 「이슬·안개·구름 비교하기」(카드 분류 groups, 카드 8장)를 덧붙이고 standards를 6과06-02, 6과06-03으로 고쳤다(`docs/specs/g5-weather-dew-fog-cloud-ext.md`). 카드의 특징 표와 관찰 문장은 교사 검수 대상이다.
4. **학년**: 앱의 3·4학년, 5·6학년 구분은 교과서 배치를 따른 것이다. 원문으로는 확인할 수 없다.
