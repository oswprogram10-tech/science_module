## 0. 공통 결정
- 여덟 실험 모두 기존 단원 `experiments` 끝에 덧붙이는 **새 활동**이다.
  - 실험마다 새 모듈을 만든다(`apps/student/src/modules/<id>`).
  - 모델은 해당 엔진 패키지(`packages/engines/<영역>`)에 순수 함수로 둔다.
- 각 단원의 첫 활동 내용과 튜터 시나리오는 바이트 단위로 그대로 둔다. standards에 새 성취기준을 더한다.
- 변인 실험 공통 틀을 쓴다.
  - 예측
  - 한 번에 하나만 바꾸기 게이트(`requireSingleIV`)
  - 결과표
  - 눈으로 보기 화면, 그래프, 모의 센서
  - 실행 전에는 결과를 그리지 않는다.
- 대조 변인을 하나씩 둔다. 결과에 영향이 없는 변인으로, 아래에 "(대조)"로 표시했다.
- SVG 글자는 390·1280 px 모두에서 13 px 이상이어야 한다. 겹침·잘림이 없어야 하고, 다크 모드 대비를 지킨다.
- 튜터
  - probes는 기존 변인 실험과 같은 상황 목록을 쓴다(before-run, first-trial, confounded, iv-unchanged, repeat, fair-test 일반 + iv별, prediction-mismatch). 모두 질문형이다.
  - 교사 문서의 "튜터 질문 초안"을 iv별 fair-test 질문에 쓴다.
  - 전수 가드를 둔다.
- 튜터 데이터
  - 시나리오를 덧붙인다(기존 줄은 그대로).
  - 예시는 단원마다 sft 2, pairs 1, redteam 1을 더한다.
- 교사 앱 튜터 질문 편집 카탈로그에 자동으로 나타나야 한다.
- 검증
  - `pnpm typecheck && pnpm test && pnpm build && pnpm e2e && pnpm tutor:validate`가 종료 코드 0이어야 한다.
  - 단위 테스트: 모델 표 고정, 대조 변인 무영향, 반올림 경계, 전수 가드, 실행 전 결과 그림 없음
  - E2E: 실험마다 기준 실행 → iv 하나만 바꾸기 → 대조 변인 바꾸기 → 그래프 축
  - 기존 기대값은 활동 수·시나리오 수·성취기준 수만 조정한다.
- 문서: `docs/curriculum-standards.md`, README, `docs/testing.md`, `ml/tutor/README.md`

## 3. g4-magnet 두 번째 활동 `magnet-poles` (4과09-02) — B1
- 제목: "자석과 자석 사이"
- 탐구 질문: "자석과 자석을 가까이 하면 어떤 일이 생길까?"
- 예측: "예측: 오른쪽 자석은 어느 쪽으로 움직일까?"
- 변인
  - `facing` "마주 보는 극": N극–N극 / N극–S극 / S극–S극. 기본 N극–S극.
  - `gapCm` "두 자석 사이 거리": 1 / 2 / 4 cm. 기본 1.
  - `size` "자석 크기": 작은 자석 / 큰 자석
  - `cover` "자석 겉 색칠"(대조): 빨강·파랑 / 회색
- 결과
  - `motion` "오른쪽 자석의 움직임"(범주): 다가와 붙음 / 밀려남 / 움직이지 않음
  - `moveCm` "움직인 거리(cm)": 소수 첫째 자리
- 모델: F = s / gap². s는 작은 자석 1, 큰 자석 2이다. F < 0.1이면 움직이지 않는다.
  - 다른 극: 다가와 붙고, 움직인 거리 = gap
  - 같은 극: 밀려나고, 거리 = min(6, round(4F, 1))
  - 표 고정
    - 작은 자석, 같은 극: gap 1 → 4.0, 2 → 1.0, 4 → 움직이지 않음 0.0
    - 큰 자석, 같은 극: 1 → 6.0, 2 → 2.0, 4 → 0.5
    - 작은 자석, 다른 극: gap 4 → 움직이지 않음
- 화면
  - 눈으로 보기: 막대자석 두 개를 그린다. 극 글자 N/S와 색을 함께 쓰고, 대조 변인에 따라 색이 회색이 된다. 옆에 나침반 두 개를 놓아 바늘이 자석 끝을 가리킨다.
  - 그래프: x는 시간(초) 0~2, y는 두 자석 사이 거리(cm) 0~10이다.
- limits: 자기장, 자기력선, 테슬라, 인력, 척력
- forbiddenAnswers
  - "같은 극끼리 밀", "같은 극끼리는 밀어"
  - "다른 극끼리 끌", "다른 극끼리는 끌어"
  - "가까울수록 세게", "멀수록 약해"
  - "색칠은 관계없"

## 4. g5-solution 두 번째 활동 `concentration` (6과03-02) — B2
- 제목: "용액의 진하기 비교하기"
- 탐구 질문: "녹인 설탕의 양이 다르면 용액의 진하기를 어떻게 비교할 수 있을까?"
- 예측: "예측: 방울토마토는 어디쯤 뜰까?"
- 변인
  - `spoons` "넣은 설탕": 1 / 3 / 5숟가락(1숟가락 = 5 g). 기본 1.
  - `waterMl` "물의 양": 50 / 100 mL. 기본 100.
  - `sugar` "설탕 종류": 황설탕 / 흰 설탕. 색 비교가 되는지 알아보는 변인이다.
  - `cup` "비커 모양"(대조): 낮은 비커 / 높은 비커
- 결과
  - `float` "방울토마토가 뜬 높이(눈금 0~10)": 정수
  - `mass20` "20 mL의 무게(g)": 소수 첫째 자리
  - `color` "색의 진하기(눈금 0~10)": 정수. 흰 설탕은 0이다.
- 모델
  - c = 설탕 g / (물 g + 설탕 g)
  - ρ = 1 + 0.38c
  - 20 mL 무게 = 20ρ
  - 뜬 높이 = ρ < 1.03이면 0, 아니면 min(10, round((ρ − 1.03) / 0.005))
  - 색 = 황설탕이면 min(10, round(40c))
  - 표 고정(100 mL)
    - 1숟가락: c = 4.8 %, ρ = 1.018 → 0, 20.4 g
    - 3숟가락: 13.0 %, 1.049 → 4, 21.0 g
    - 5숟가락: 20.0 %, 1.076 → 9, 21.5 g
  - 50 mL
    - 1숟가락: 9.1 % → 1
    - 3·5숟가락 → 10
- 화면
  - 눈으로 보기: 비커, 방울토마토 높이, 용액 색을 그린다.
  - 그래프: 막대(시행별 뜬 높이)로 그린다. 시간 그래프가 아니라 시행 비교이다. stream-table의 결과 막대 방식을 따른다.
- 안전 상시 안내: "실험한 용액은 맛보지 않아요."
- limits: 농도, 퍼센트, 밀도, 용해도, 포화, 부력
- forbiddenAnswers
  - "설탕을 많이 넣을수록 진", "설탕이 많을수록 진"
  - "물이 많을수록 연", "물을 많이 넣을수록 연"
  - "진할수록 방울토마토가 높이", "진할수록 높이 떠"
  - "흰 설탕은 색으로 비교할 수 없"
  - "비커 모양은 관계없"

## 5. g5-heat 두 번째 활동 `heat-contact` (6과07-02) — B2
- 제목: "온도가 다른 두 물이 닿으면"
- 탐구 질문: "온도가 다른 두 물체가 닿아 있으면 온도가 어떻게 변할까?"
- 예측: "예측: 10분 뒤 안쪽 컵 물의 온도는?"
- 변인
  - `hotC` "안쪽 컵 물의 처음 온도": 50 / 60 / 70 °C. 기본 60.
  - `coldMl` "바깥 비커 찬물의 양": 100 / 300 mL. 기본 100.
  - `cup` "안쪽 컵 재료": 얇은 금속 컵 / 플라스틱 컵. 빠르기만 바뀐다.
  - `label` "컵에 붙인 이름표 색"(대조): 노랑 / 초록
  - 고정: 안쪽 물 100 mL, 찬물 처음 20 °C
- 결과
  - `inner10` "10분 뒤 안쪽 물 온도(°C)": 정수
  - `outer10` "10분 뒤 바깥 물 온도(°C)": 정수
  - `sameMin` "두 온도 차가 1 °C 안이 된 때(분)": 정수. 20분 안에 안 되면 "20분 넘음"이다.
- 모델
  - 나중 온도 Tf = (100·Th + m·20) / (100 + m)
  - 차이 D(t) = (Th − 20) · e^(−kt), k = k₀ · 100 · (1/100 + 1/m)
  - k₀는 금속 0.6, 플라스틱 0.2(/분)
  - 안쪽 = Tf + D · m/(100+m), 바깥 = Tf − D · 100/(100+m)
  - 표 고정
    - 60 °C, 100 mL, 금속: Tf 40, k 1.2 → 10분 뒤 40·40, sameMin = ceil(ln 40 / 1.2) = 4
    - 플라스틱: k 0.4 → 10분 뒤 안 41, 바깥 39, sameMin 10
    - 300 mL, 금속: Tf 30, k 0.8 → sameMin 5
    - 300 mL, 플라스틱: k 0.267 → sameMin 14
  - 수치는 테스트에서 계산해 고정한다.
- 화면
  - 눈으로 보기: 비커 안 컵, 온도계 두 개를 그린다. 선택 보기로 열화상 색(교사 문서의 "열화상" 방식, insulated-cup의 그 화면)을 쓴다.
  - 그래프: x는 시간(분) 0~20, y는 온도(°C) 0~80이다. 선 두 개(안쪽, 바깥)를 그린다.
  - 센서: 온도계 두 개
- 안전: insulated-cup과 같은 뜨거운 물 점검표
- limits: 열평형, 비열, 열량, 칼로리, 전도
- forbiddenAnswers
  - "열이 이동", "열이 옮겨", "열이 전달"
  - "따뜻한 쪽에서 차가운 쪽으로"
  - "두 온도가 같아질 때까지", "온도가 같아져"
  - "찬물이 많을수록 더 낮아"
  - "이름표 색은 관계없"

## 6. g6-acid-base 두 번째 활동 `acid-base-mix` (6과09-02) — B2
- 제목: "산성 용액과 염기성 용액 섞기"
- 탐구 질문: "산성 용액에 염기성 용액을 조금씩 넣으면 용액의 성질은 어떻게 변할까?"
- 예측: "예측: 지시약의 색은?"
- 변인
  - `drops` "넣은 방울 수": 0 / 10 / 20 / 30 / 40. 기본 0. 한 방울은 0.5 mL이다.
  - `direction` "넣는 방향"
    - 묽은 염산 10 mL에 묽은 수산화 나트륨 용액을 넣음
    - 묽은 수산화 나트륨 용액 10 mL에 묽은 염산을 넣음
  - `indicator` "지시약": 붉은 양배추 지시약 / 페놀프탈레인 용액
  - `beaker` "비커 크기"(대조): 50 mL / 100 mL
- 결과
  - `color` "지시약 색"(범주)
  - `addedMl` "넣은 양(mL)": 소수 첫째 자리
- 모델(두 용액 모두 0.1 mol/L, 화면에 수치 비공개)
  - 처음 용액 1.0 mmol, 넣은 쪽 drops × 0.05 mmol, 부피 10 + 0.5 × drops mL
  - 남은 쪽 농도로 내부 산도 값 p를 계산한다. 같으면 7, 산이 남으면 −log₁₀, 염기가 남으면 14 + log₁₀.
  - 색
    - 붉은 양배추: p < 3 빨간색, < 6 분홍색, < 8 보라색, < 10 푸른색, < 12 초록색, 그 이상 노란색
    - 페놀프탈레인: p < 8.2 색이 없음, 그 이상 붉은색
  - 표 고정(염산에 넣기, 붉은 양배추)
    - 0방울: 빨간색
    - 10: p = 1.5 → 빨간색
    - 20: 7 → 보라색
    - 30: p = 12.3 → 노란색
    - 40: 12.5 → 노란색
  - 단원 첫 활동의 지시약 색 이름과 맞춘다. 맞지 않으면 첫 활동 매니페스트의 색 이름 체계를 따르고 보고한다.
- 화면
  - 눈으로 보기: 비커, 스포이트, 색을 그린다.
  - 그래프 대신 "색 띠 기록": 시행마다 방울 수 위치에 색 칸을 찍는다.
  - SVG에 색 이름을 글자로 함께 쓴다(색각 접근성).
- 안전: 첫 활동과 같은 보안경·장갑 점검표
- limits: pH, 수소 이온, 수산화 이온, 몰, 중화열, 염
- forbiddenAnswers
  - "중화", "중성이 되"
  - "산성이 약해", "염기성이 약해"
  - "산성이 점점 약해", "염기성으로 변"
  - "비커 크기는 관계없"
