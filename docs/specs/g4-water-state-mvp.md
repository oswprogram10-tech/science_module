# 구현 사양: 4학년 「물의 상태 변화」 최소 실험 (v0) — 물이 얼 때와 얼음이 녹을 때의 부피와 무게

> 앞 사양: `phase2-roadmap.md`(순서 13). 물질 엔진 단원(`dissolution`, `gas-syringe`)과 미시 입자 화면이 본보기다.
> 새 변인 실험 모듈은 `freeze-melt`이다(`@sci/engine-matter`, `phase.ts`).

## 0. 결정

- 한 시행은 "얼리기" 또는 "녹이기" 하나를 30분 동안 한다.
  - 얼리기: 시험관의 물을 소금 얼음물에 넣는다.
  - 녹이기: 같은 양의 물을 미리 얼린 얼음을 따뜻한 물에 넣는다.
- 주 측정값은 **부피 변화(mL, 부호 포함)**이다. 시행 간 비교(늘어났다/줄어들었다/변하지 않았다)가 이 값으로 이루어진다.
- 무게는 변하지 않는다. 그런데 "무게 변화 0" 열은 모든 시행에서 같아 의미가 없다. 그래서 무게 열은 `"처음 → 나중"` 글자(예: "10.0 g → 10.0 g")로 보인다. 이 열은 처음 양에 따라 달라지고, 그대로임을 한눈에 보여 준다.
- 부피 증가율 9%는 근사이며 **교사 검수 대상**이다. 용어는 "고체", "액체", "부피", "무게"를 쓴다. 밀도·분자·수소 결합·잠열은 쓰지 않는다. 미시 화면은 "알갱이"라고 부른다.

## 1. 실험 개요

- **탐구 질문**: "물이 얼거나 얼음이 녹을 때 부피와 무게는 어떻게 달라질까?"
- **조건 3가지**
  - 과정: 물 얼리기 / 얼음 녹이기
  - 처음 물의 양: 10 mL / 20 mL. 녹이기에서는 이 양의 물을 얼린 얼음이다.
  - 시험관 종류: 유리 / 플라스틱 — 대조 변인, 영향 없음
- **측정**: 부피 변화(mL), 나중 부피(mL), 무게(처음 → 나중, g)
- **학습 의도**
  - 물이 얼면 부피가 늘어나고, 얼음이 녹으면 부피가 줄어든다.
  - 두 경우 모두 무게는 변하지 않는다.
  - 물이 많을수록 부피가 더 많이 변한다.
  - 얼거나 녹는 동안 온도는 0 °C에 머문다. 이는 센서 그래프로만 보여 주고 결과표에는 넣지 않는다.

## 2. 모델 (`@sci/engine-matter`, `phase.ts`)

- **입력과 옵션**
  - 입력: `{ process: 'freeze'|'melt', startMl: number, tube: 'glass'|'plastic' }`
  - `opts = { totalMin = 30, sampleEveryMin = 0.1 }`
- **시간 구간**: `tCool = 2 + 0.2·V0`(분), `tChange = 1.0·V0`(분), `tEnd = tCool + tChange`. 10 mL는 4/14, 20 mL는 6/26이다.
- **얼린 몫** f(t)
  - freeze: tCool까지 0, tCool~tEnd 동안 0→1로 선형, 그 뒤 1
  - melt: 처음 1, tCool~tEnd 동안 1→0으로 선형, 그 뒤 0
- **부피** `V(t) = V0·(1 + 0.09·f)`. **부피 변화** `dV(t) = V(t) − V(0)`
- **무게** `m = V0·1.0`(g), 일정
- **온도**(센서용, °C)
  - freeze: 0~tCool은 20→0 선형, 그다음 tEnd까지 0, 그 뒤 `−10 + 10·e^(−(t−tEnd)/3)`
  - melt: 0~tCool은 −8→0 선형, 그다음 tEnd까지 0, 그 뒤 `25 − 25·e^(−(t−tEnd)/8)`
- **샘플**: `{ t, dV, volume, frozen: f, tempC, massG }`. 마지막 샘플은 t = 30이다.
- **결과**
  - `dV`: 소수 첫째 자리, 부호 포함
  - `volumeEnd`: 소수 첫째 자리
  - `mass`: 문자열 `"{m.toFixed(1)} g → {m.toFixed(1)} g"`이다. 숫자 필드 `massStart`, `massEnd`도 둔다.
- **`validatePhaseExperiment(exp)`**: 세 변인이 있는지, 값이 허용 범위인지 검사한다. V0 5~25이고 tEnd ≤ totalMin이어야 한다.
- 순수 함수, 난수 없음. tube는 계산에 쓰지 않는다.

### 2.1 기준값 (테스트로 고정, 시험관 두 가지 모두)

| 과정 | 처음 양 | 부피 변화(mL) | 나중 부피(mL) | 무게 |
|---|---|---|---|---|
| 얼리기 | 10 | +0.9 | 10.9 | 10.0 g → 10.0 g |
| 얼리기 | 20 | +1.8 | 21.8 | 20.0 g → 20.0 g |
| 녹이기 | 10 | −0.9 | 10.0 | 10.0 g → 10.0 g |
| 녹이기 | 20 | −1.8 | 20.0 | 20.0 g → 20.0 g |

### 2.2 반드시 통과할 테스트

- 표 4칸을 시험관 두 가지 각각으로 고정한다.
- 시험관만 바꾸면 결과와 샘플이 같다.
- freeze에서 dV는 단조 비감소이고, melt에서는 단조 비증가이다.
- tCool~tEnd 동안 tempC는 0이다.
- 모든 샘플의 massG가 같다.

## 4. 화면 (`apps/student/src/modules/freeze-melt/`)

- **거시(SVG) "눈으로 보기"**
  - 비커(소금 얼음물 또는 따뜻한 물) 속 시험관을 그린다. 시험관 속 물과 얼음은 frozen 비율로 아래부터 얼음 질감이 차오른다(녹이기는 반대).
  - 처음 높이에 고무줄 표시선을 두고, 지금 높이선과 차이를 보인다.
  - 옆에 전자저울 그림과 무게 숫자(massG)를 둔다.
  - 아래 문구: `"{t}분 · 부피 {volume} mL · 무게 {massG} g · {tempC} °C"`
- **미시 자리(SVG) "알갱이 보기"**
  - 물 알갱이 점 18~24개를 그린다.
    - 액체: 가깝고 불규칙하게 놓이며 조금씩 움직인다.
    - 얼음: 일정한 육각 무늬로 놓이고 사이 간격이 조금 더 넓다.
  - frozen 비율만큼 얼음 배치로 섞는다.
  - **알갱이 개수는 언제나 같다.** 무게 그대로를 그림으로 보이고, 화면에 "알갱이 수 {n}개"를 쓴다.
  - 라벨: "물(액체)", "얼음(고체)". 그림 아래 문구: "얼음이 될 때 알갱이 수는 같고, 알갱이 사이가 조금 넓어져요." 이 문장은 화면 설명이며, 금지 구절과 겹치는지 확인한다.
  - reduced-motion이면 정지한다.
- **그래프**
  - y = dV, 라벨 `부피 변화(mL)`, y −2~2 고정(yTicks −2·−1·0·1·2). 음수 축은 g3-sound에서 지원한 기능을 쓴다. 아직 없으면 필요한 만큼 일반화한다.
  - x 라벨 `시간(분)`, xTicks 0·5·…·30
  - markers는 함수형으로 둔다. tCool에 "얼기 시작"/"녹기 시작", tEnd에 "다 얼었어요"/"다 녹았어요"이다.
- **센서**: "가상 온도계"(tempC, 기존 temperature kind), "가상 전자저울"(massG, 기존 scale kind)
- **결과 열**: 부피 변화(mL, + 기호 표시), 나중 부피(mL), 무게(처음 → 나중)
- **예측 비교**: metric = dV, `sameThreshold` = 0.05
- **재생 후 플레이헤드**: `restPlayhead` = 30
