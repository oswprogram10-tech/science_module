# 구현 사양: 4학년 「기후변화와 우리 생활」 최소 실험 (v0) — 온실 모형

> 앞 사양: `phase2-roadmap.md`(순서 20), `g3-health-mvp.md`(`@sci/engine-ssi` 새 패키지). 이 단원은 그 패키지에 `greenhouse.ts`를 더한다.
> 새 변인 실험 모듈은 `greenhouse-bottle`이다.

## 0. 결정

- 같은 페트병 두 개 중 하나를 쓰는 대신, 시행마다 페트병 하나를 전등(태양 대신)으로 20분 동안 비추고 병 속 공기 온도를 잰다.
- 조건
  - 투명 비닐 덮개(지구를 둘러싼 공기층 비유)
  - 병 속 공기(보통 공기 / 이산화 탄소를 더 넣은 공기)
- **이산화 탄소 효과는 작게 둔다.** 교실 페트병 실험에서 이 효과는 작고 다른 요인에 쉽게 묻힌다. 결과표의 차이(+1.4 °C)가 덮개 효과(+3.9 °C)보다 작은 것이 정직한 모델이다. 튜터와 교사용 문서에 "모형 실험의 한계"를 적는다.
- "기후 자료 그래프"(실제 관측 자료)는 v0에서 넣지 않는다. 이후 확장으로 서울 연평균기온 그래프를 접힌 패널로 추가했다(`g4-climate-data-ext.md`).
- 근사 모델이며 **교사 검수 대상**이다. 복사 평형·적외선 흡수 같은 용어는 쓰지 않는다. "온실 기체"는 4학년 교육과정 용어로 쓴다.

## 1. 실험 개요

- **탐구 질문**: "공기층을 덮거나 이산화 탄소를 늘리면 병 속 온도는 어떻게 달라질까?"
- **조건 3가지**
  - 투명 비닐 덮개: 없음 / 씌움
  - 병 속 공기: 보통 공기 / 이산화 탄소를 더 넣은 공기
  - 병 뚜껑 색: 흰색 / 파란색 — 대조 변인, 영향 없음
- **측정**: 20분 뒤 온도(°C), 오른 온도(°C)
- **학습 의도**
  - 공기층이 열이 빠져나가는 것을 막으면 온도가 더 오른다(온실 효과의 비유).
  - 이산화 탄소 같은 온실 기체가 많아지면 온도가 조금 더 오른다.
  - 이 모형은 실제 지구와 다른 점이 있다.

## 2. 모델 (`@sci/engine-ssi`, `greenhouse.ts`)

- **입력과 옵션**
  - 입력: `{ cover: 'none'|'film', air: 'normal'|'co2', cap: 'white'|'blue' }`
  - `opts = { totalMin = 20, sampleEveryMin = 0.1 }`
- **처음 온도** Ta = 22 °C, 시간 상수 τ = 6분
- **오를 수 있는 최대 온도 차** `R = 6 + (film ? 4 : 0) + (co2 ? 1.5 : 0)`
- **온도** `T(t) = Ta + R·(1 − e^(−t/τ))`
- **샘플**: `{ t, temp, rise: T − Ta, trapped (화면용 0~1: R/11.5) }`. 마지막 샘플은 t = 20이다.
- **결과**: `temp`, `rise`(소수 첫째 자리, rise는 반올림 전 값으로 계산하고 표시 temp − 22와 같음을 테스트)
- **`validateGreenhouseExperiment(exp)`**: 세 변인이 있는지, 값이 허용 범위인지 검사한다.
- 순수 함수, 난수 없음. cap은 계산에 쓰지 않는다.

### 2.1 기준값 (테스트로 고정, 뚜껑 두 가지 모두)

| 덮개 | 공기 | 20분 뒤(°C) | 오른 온도(°C) |
|---|---|---|---|
| 없음 | 보통 | 27.8 | 5.8 |
| 없음 | 이산화 탄소 | 29.2 | 7.2 |
| 씌움 | 보통 | 31.6 | 9.6 |
| 씌움 | 이산화 탄소 | 33.1 | 11.1 |

반올림 전 rise: 5.786, 7.232, 9.643, 11.089

### 2.2 반드시 통과할 테스트

- 표 4칸을 뚜껑 두 가지 각각으로 고정한다.
- 뚜껑만 바꾸면 결과와 샘플이 같다.
- temp는 단조 증가한다.
- 모든 조건에서 (덮개 효과) > (이산화 탄소 효과)이다.

## 4. 화면 (`apps/student/src/modules/greenhouse-bottle/`)

- **거시(SVG) "눈으로 보기"**
  - 전등, 페트병(뚜껑 색), 병 속 디지털 온도계를 그린다.
  - 덮개를 씌우면 병 둘레에 투명 비닐 막(점선 테두리와 반사광)을 그린다.
  - 이산화 탄소면 병 아래에 "이산화 탄소 +" 이름표를 붙인다. 기체는 보이지 않으므로 점이나 연기로 그리지 않는다.
  - 아래 문구: `"{t}분 · 병 속 {temp} °C (처음보다 +{rise} °C)"`
- **미시 자리(SVG) "열이 드나드는 모습 보기"**
  - 들어오는 빛 화살표(노랑)와 빠져나가는 열 화살표(빨강)를 그린다.
  - 빠져나가는 화살표 중 일부가 덮개나 이산화 탄소 층에서 되돌아온다. 되돌아오는 개수는 trapped에 비례한다.
  - 라벨: "들어오는 빛", "빠져나가는 열", "되돌아오는 열"
  - 그림 아래 문구: "공기층은 담요처럼 열이 빠져나가는 것을 늦춰요." 화면 설명이며, 금지 구절과 겹치는지 확인한다.
  - 그림 옆에 "모형의 한계" 접힘 글을 둔다: "실제 지구는 병보다 훨씬 크고, 바다·구름·숲 같은 많은 것이 함께 영향을 줘요."
- **그래프**
  - y = temp, 라벨 `병 속 온도(°C)`, y 20~35 고정(yTicks 20·25·30·35)
  - x 라벨 `시간(분)`, xTicks 0·5·10·15·20
- **센서**: "가상 온도계: 병 속"(temp, 기존 temperature kind)
- **결과 열**: 오른 온도(°C, + 표시), 20분 뒤 온도(°C)
- **예측 비교**: metric = rise, `sameThreshold` = 0.2
- **재생 후 플레이헤드**: `restPlayhead` = 20
