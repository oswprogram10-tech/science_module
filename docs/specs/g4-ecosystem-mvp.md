# 구현 사양: 4학년 「생물과 환경」 최소 실험 (v0) — 먹이 관계와 생태계 평형

> 앞 사양: `phase2-roadmap.md`(순서 3). 가장 가까운 본보기는 생명 엔진 단원 `g3-lifecycle`·`g6-plant`이다.
> 새 변인 실험 모듈은 `food-web`이다(`@sci/engine-life`, 파일 `foodweb.ts`).

## 1. 실험 개요

- **탐구 질문**: "풀, 토끼, 여우가 사는 곳에서 어떤 조건이 바뀌면 생물의 수는 어떻게 달라질까?"
- **조건 4가지**:
  - 처음 토끼 수: 10 / 20마리
  - 처음 여우 수: 0 / 2 / 4마리
  - 비가 오는 정도: 적게 / 보통 / 많이(풀이 자라는 빠르기, 비생물 요소)
  - 토끼 털 색: 흰색 / 갈색(대조 변인, 결과에 영향 없음)
- **측정**: 60일 동안의 풀의 양(%)과 토끼·여우 수. 60일 뒤 풀의 양, 60일 뒤 토끼 수, 60일 뒤 여우 수, 가장 많았던 토끼 수.
- **학습 의도**
  - 여우가 없으면 토끼가 크게 늘어 풀을 거의 다 먹는다. 그러면 토끼도 먹이가 모자라 줄어든다. 먹이 관계의 한 고리가 빠지면 생태계 평형이 깨진다.
  - 여우가 있으면 토끼가 크게 늘지 않아 풀이 유지된다.
  - 비(비생물 요소)가 많으면 풀이 잘 자라 생물 수가 모두 늘어나는 쪽으로 간다.
  - 털 색은 아무 영향이 없다.
- **용어**: "생태계", "먹이 사슬", "먹이 그물", "생산자", "소비자", "생태계 평형", "비생물 요소"는 쓴다(교육과정 용어). 개체군·로트카·미분 등은 쓰지 않는다.

## 2. 먹이 관계 모델 (`@sci/engine-life`, `foodweb.ts`)

교육용 단순화 모델이며 **교사 검수 대상**이다. 결과가 기준값과 같도록 **아래 계산 순서를 그대로** 구현한다.

- **입력과 옵션**
  - 입력: `{ rabbits0: number, foxes0: number, rain: 'low'|'normal'|'high', furColor: string }`
  - `opts = { days = 60, dt = 0.05, grass0 = 80 }`
- **상수**
  - 풀 자라는 빠르기 rg: low 0.04, normal 0.08, high 0.12
  - regrow 0.1, b 0.10, starve 0.06, a 0.02, conv 0.3, fd 0.04
- **계산**: 매 dt마다(G = 풀 %, R = 토끼, F = 여우, 모두 실수)
  1. `food = G/(G+20)`, `eat = 0.6·R·food`
  2. `dG = rg·G·(1−G/100) + regrow·rg·10 − 0.5·eat`
  3. `pred = a·R·F/(1+0.02·R)`
  4. `dR = b·R·food − (0.03 + starve·(1−food))·R − pred`
  5. `dF = conv·pred − fd·F`
  6. `G = clamp(G + dG·dt, 0, 100)`, `R = max(0, R + dR·dt)`, `F = max(0, F + dF·dt)`
- **샘플**: 매일(t가 정수일 때, 갱신 전 값) `{ t, grassPct, rabbits, foxes }`. 화면의 동물 수는 반올림해서 보여 준다.
- **결과**
  - `grassDay60`: 반올림 정수
  - `rabbitsDay60`, `foxesDay60`: 반올림
  - `rabbitsMax`: 샘플 중 최댓값을 반올림
- 털 색은 계산에 쓰지 않는다.
- **`validateFoodWebExperiment(exp)`**: 변인이 있는지, 값이 허용 범위인지 검사한다. 토끼 1~50, 여우 0~10, rain 세 종.
- 순수 함수, 난수 없음.

## 4. 화면 (`apps/student/src/modules/food-web/`)

- **거시(SVG) "눈으로 보기"**
  - 풀밭 풍경: 풀 무더기 수와 초록 진하기는 grassPct에 비례한다. 토끼와 여우 아이콘은 반올림한 수만큼 그리되 최대 30·10개로 하고, 넘으면 "+n"을 붙인다.
  - 비가 오는 정도는 구름과 빗줄기 개수로 보여 주고 글자 라벨을 함께 쓴다. 토끼 털 색을 반영한다.
  - 아래 문구: `"{t}일째 · 풀 {G}% · 토끼 {R}마리 · 여우 {F}마리"`
- **미시 자리(SVG) "먹이 그물로 보기"**
  - 풀 → 토끼 → 여우 화살표("먹힘")와 해·비 → 풀(비생물 요소).
  - 각 칸에 현재 수를 쓰고, 칸 크기는 수에 비례한다(최소·최대 크기 제한).
  - 여우가 0이면 여우 칸을 점선으로 그리고 "없음"이라고 쓴다.
  - 그림 아래 문구: "화살표는 먹고 먹히는 관계를 나타내요."
- **그래프**: 세 선을 그린다(풀 %, 토끼 수, 여우 수).
  - 지금 GraphView는 선 하나(sampleKey)만 지원한다. 모듈 선택 필드 `graph.series?: {key, label, color, dash?}[]`를 추가해 여러 선을 그린다(기존 단원은 변화 없음).
  - y축은 0~100 하나로 함께 쓰고, 라벨은 `수(마리) / 풀의 양(%)`이다. 범례는 글자, 선 모양(실선·점선·점점선), 색을 함께 쓴다.
  - 앞 시행 선은 metric(풀)만 흐리게 겹쳐 그린다.
  - x 라벨 `날짜(일)`, xTicks 0·10·…·60.
- **센서**: 없음. 센서 막대를 숨길 수 없다면 "가상 비 측정기(mm/일)"를 둔다(low 2, normal 5, high 8). 다른 방법이 있으면 보고한다.
- **결과 열**: 60일 뒤 풀(%), 60일 뒤 토끼(마리), 60일 뒤 여우(마리), 가장 많았던 토끼(마리).
- **예측 비교**: metric = grassDay60(풀), `sameThreshold` = 2(%).
- **재생 후 플레이헤드**: `restPlayhead` = 60.
