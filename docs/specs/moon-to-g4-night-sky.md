# 이동 사양: 달 모양 과제를 6학년 「지구의 운동」에서 4학년 「밤하늘 관찰」로 옮김

> 근거: 교육과정 원문(교육부 고시 제2022-33호 [별책 9])은 달의 위상 변화를 3~4학년 「밤하늘 관찰」(4과13-01)에 둔다. 6학년 「지구의 운동」(6과12)에는 달이 없다. 대조 결과는 `docs/curriculum-standards.md`에 있다.
> 앞 사양 `g6-moon-phase-ext.md`(달 모델, 보기 `moon`, 과제 2개)의 모델·화면·과제 내용은 바꾸지 않고 **자리만 옮긴다**.

## 0. 결정

### 4학년 「밤하늘 관찰」 (`content/units/g4-night-sky/manifest.json`)
- 과제 `moon-change`와 `full-moon`을 기존 과제 4개 **뒤에** 덧붙인다. 순서는 이 둘 그대로이다.
- 덧붙이는 범위
  - 과제 정의(질문·선택지·answer·view `moon`·probes)를 글자 그대로 옮긴다.
  - 달 관련 forbiddenAnswers 16개를 옮긴다(아래 목록).
  - limits에 `위상`, `이각`, `삭망월`, `황도`를 더한다. 앞의 셋은 기존 g4 limits에 없다. `황도`도 g4에 없으니 함께 더한다.
- `standards`는 `["4과13-01", "4과13-02", "4과13-03"]`로 바꾼다.
- 달 모델(서울 북위 37.5°, 저녁 7시, `g6-moon-phase-ext.md` §1)은 그대로이다.
  - g4의 params가 g6와 다르면(예: `latDeg`) 달 모델이 37.5°를 쓰는지 확인한다.
  - `g6-moon-phase-ext.md` §1 기준값 표(d=1,3,8,10,15,22)와 정답 규칙("waxes-east", "15")이 g4에서도 **같아야 한다.** 다르면 멈추고 보고한다.
- 옮기는 forbiddenAnswers 16개
  - 점점 차올라 / 점점 차오르 / 점점 차오른
  - 차오르면서 동쪽 / 차오르며 동쪽
  - 보름달은 음력 15일 / 보름달은 15일 / 15일 무렵에 보름달 / 15일쯤 보름달
  - 동쪽으로 옮겨 가 / 동쪽으로 옮겨 갑 / 동쪽으로 옮겨 간
  - 달은 스스로 빛을 내지 않 / 달은 스스로 빛나지 않
  - 햇빛을 받는 부분 / 햇빛을 받는 쪽
- 전수 가드
  - g4의 **기존** probe와 화면 문구가 새로 더한 금지 구절·limits에 걸리지 않아야 한다.
  - 옮긴 달 과제의 probe와 화면 문구는 g4의 **기존** 금지 구절·limits에 걸리지 않아야 한다.
  - 걸리면 멈추고 보고한다. 문구를 임의로 바꾸지 않는다.

  - 다른 점은 `standards`(현재 값 `["6과12-01","6과12-02","6과12-03"]`) 하나뿐이어야 한다.

## 1. 테스트
- **단위 테스트** (`apps/student/src/modules/sky-observation/moon.test.ts` 등)
  - 달 과제 테스트가 g4 매니페스트를 보게 한다.
  - g6 매니페스트가 달 이전과 같은지(standards 빼고) 확인한다.
  - g4 기존 과제 4개의 보기 종류가 그대로인지 확인한다.
  - g4 달 과제가 맨 뒤 2개인지 확인한다.
  - 모델 기준값 표와 정답 규칙을 확인한다.
  - 두 단원의 전수 가드를 확인한다.
- **E2E**
  - `earth-motion.spec.ts`의 달 테스트를 `night-sky.spec.ts`로 옮긴다.
    - 슬라이더 3일→10일
    - 18일 "보이지 않아요"
    - 기록 전 이름 없음
    - full-moon 15
    - 390 px 가로 스크롤 없음
  - earth-motion의 과제 수는 5개로 돌아간다. night-sky의 과제 수는 6개가 된다.
  - `svg-text.spec.ts`, `layout.spec.ts`, `a11y.spec.ts`가 g4의 달 보기를 검사하게 한다. 예전에 g6에서 하던 검사를 그대로 옮긴다.
- 기존 기대값은 바꾸지 않는다. 과제 수, 시나리오 수, 매니페스트 해시, 성취기준만 조정한다.
- `pnpm typecheck && pnpm test && pnpm build && pnpm e2e`가 모두 종료 코드 0이어야 하고, `pnpm tutor:validate`가 통과해야 한다.
