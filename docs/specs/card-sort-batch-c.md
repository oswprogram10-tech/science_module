## 0. 공통 결정
- 1차 묶음(`card-sort-batch-a.md`) 0장의 공통 결정을 그대로 따른다.
  - module card-sort, layout groups. 기존 단원 `experiments` 끝에 덧붙인다.
  - 기존 활동의 내용과 튜터 시나리오는 바이트 단위로 그대로 둔다.
  - 관찰 문장에는 보이는 사실만 쓴다. 정답 무리 이름(고체, 액체, 기체 등)을 관찰 문장, 기준 문장, 화면 문구, probe에 쓰지 않는다.
  - 카드 그림은 단순 SVG, 그림 안에 글자 없음.

- 선생님이 정할 것(초안 문서의 「정할 것」)은 아래 기본값으로 만든다. 문서에 그대로 남겨 두어 수업 전에 고칠 수 있게 한다.
