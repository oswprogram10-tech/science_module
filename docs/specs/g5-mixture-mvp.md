# 구현 사양: 5학년 「혼합물의 분리」 최소 실험 (v0) — 소금과 모래 분리하기

> 앞 사양: `phase2-roadmap.md`(순서 14). 물질 엔진 `dissolution`(용해도 표 `solubility.ts`)을 재사용한다. 그래서 용해와 용액 단원과 수치가 이어진다.
> 새 변인 실험 모듈은 `salt-sand`이다(`@sci/engine-matter`, `separation.ts`).

## 0. 결정

- 로드맵 초안은 "분리 방법 선택(체·자석·거름·증발)"이었다. v0에서는 교과서의 대표 실험인 **소금+모래 혼합물을 녹이기 → 거르기 → 증발시키기**를 변인 실험으로 만든다.
  - 학생은 물의 양과 거르는 방법을 바꾼다.
  - 체·자석 분리는 이후 카드형 확장 과제로 남긴다(로드맵에 메모).
- 주 측정값은 **얻은 소금의 양(g)**이다.
  - 물이 적으면 소금이 다 녹지 않아 덜 얻는다. 용해도 표의 20 °C 값을 쓴다.
  - 거름종이 없이 따르기만 하면 얻는 소금은 같지만 모래가 섞인다. 이것은 "섞인 모래(g)" 열에서 보인다. "결과: 변하지 않았다"(소금)와 모래 열의 차이를 함께 보도록 튜터가 묻는다.
- 거름종이에 젖은 모래가 거른 물의 일부(10%)를 붙잡는 손실이 있다. 근사이며 **교사 검수 대상**이다.
- 용어는 "혼합물", "거름", "증발", "용해"를 쓴다. 순도·포화·결정 성장 같은 말은 쓰지 않는다.

## 1. 실험 개요

- **탐구 질문**: "소금과 모래가 섞인 혼합물에서 소금을 어떻게 분리할 수 있을까?"
- **혼합물**: 모래 10 g + 소금 10 g. 물 온도는 20 °C이다.
- **조건 3가지**
  - 넣는 물의 양: 20 mL / 50 mL
  - 거르는 방법: 거름종이로 거르기 / 거름종이 없이 윗물만 따르기
  - 젓는 도구: 유리 막대 / 나무 젓가락 — 대조 변인, 영향 없음
- **진행**(20분)
  - 0~3분: 물을 넣고 저어 녹인다.
  - 3~8분: 거르거나 따른다.
  - 8~20분: 증발 접시에서 가열해 물을 날린다.
- **측정**: 얻은 소금(g), 섞인 모래(g)
- **학습 의도**
  - 소금은 물에 녹고 모래는 녹지 않는다는 성질 차이를 이용해 분리한다.
  - 물이 너무 적으면 소금이 다 녹지 않아 덜 얻는다.
  - 거름종이로 걸러야 모래가 섞이지 않는다.
  - 젓는 도구는 관계없다.

## 2. 모델 (`@sci/engine-matter`, `separation.ts`)

- **입력과 옵션**
  - 입력: `{ waterMl: number, filter: 'paper'|'pour', stirrer: 'glass'|'wood' }`
  - `opts = { totalMin = 20, sampleEveryMin = 0.1 }`
  - 상수: 소금 10 g, 모래 10 g, 거름 통과 비율 0.9, 따르기로 넘어가는 모래 1.5 g
- **녹는 양**: `S = solubility('salt', 20)`(g/100 g 물, 기존 함수. 20 °C는 35.9)를 쓴다. `dissolved = min(10, waterMl·S/100)`이다. 물 1 mL = 1 g이다.
  - 0~3분 동안 녹은 양은 0에서 dissolved까지 `1 − e^(−t/0.6)` 모양으로 늘고, 3분에서 정확히 dissolved로 맞춘다.
- **거른 물**: 물 `Wf = 0.9·waterMl`, 소금 `saltF = 0.9·dissolved`. pour이면 모래 1.5 g이 함께 넘어가고, paper이면 0이다. 3~8분 동안 접시로 옮겨지는 비율은 선형이다.
- **증발**: 8~20분 동안 접시의 물 `W(t)`가 Wf에서 0까지 선형으로 줄어든다.
  - 접시 위 고체 `solid(t) = sandF + max(0, saltF − W(t)·S/100)`. 8분 이전은 sandF이다(거르는 중에는 모래만 보임).
- **샘플**: `{ t, dissolvedG, dishWaterMl, solidG, saltOnDishG, stage: 'dissolve'|'filter'|'evaporate' }`. 마지막 샘플은 t = 20이다.
- **결과**: `salt` = saltF(소수 첫째 자리), `sand` = sandF(소수 첫째 자리), `total` = salt + sand(화면 문구용)
- **`validateSeparationExperiment(exp)`**: 세 변인이 있는지, 값이 허용 범위인지 검사한다. 물 10~100 mL.
- 순수 함수, 난수 없음. stirrer는 계산에 쓰지 않는다.

### 2.1 기준값 (테스트로 고정, 젓는 도구 두 가지 모두)

| 물 | 거르기 | 얻은 소금(g) | 섞인 모래(g) |
|---|---|---|---|
| 20 mL | 거름종이 | 6.5 | 0.0 |
| 20 mL | 따르기 | 6.5 | 1.5 |
| 50 mL | 거름종이 | 9.0 | 0.0 |
| 50 mL | 따르기 | 9.0 | 1.5 |

반올림 전 값: 20 mL에서 dissolved는 7.18, saltF는 6.462이다. 50 mL에서 dissolved는 10, saltF는 9.0이다.

### 2.2 반드시 통과할 테스트

- 표 4칸을 젓는 도구 두 가지 각각으로 고정한다.
- 젓는 도구만 바꾸면 결과와 샘플이 같다.
- solidG는 단조 비감소이다.
- 20분에 dishWaterMl은 0이고 solidG = salt + sand이다(반올림 전 값 기준).
- dissolved는 solubility 함수 값과 일치한다(용해와 용액 단원과 같은 표).

## 4. 화면 (`apps/student/src/modules/salt-sand/`)

- **거시(SVG) "눈으로 보기"**는 단계 세 칸이다. 지금 단계는 강조하고, 다른 칸은 흐리게 하되 내용은 보인다.
  1. 비커: 물(waterMl 눈금), 바닥 모래, 녹지 않은 소금 알갱이(10 − dissolved에 비례), 젓는 도구
  2. 깔때기와 거름종이(또는 따르는 비커): 아래 비커에 모이는 물, pour이면 섞여 넘어가는 모래 점
  3. 알코올램프 위 증발 접시: 남은 물 높이, 하얀 소금 가루와 모래 점(solidG에 비례)
  - 아래 문구: `"{t}분 · {단계 이름} · 접시 위 가루 {solidG} g"`
- **미시 자리(SVG) "알갱이 보기"**
  - 비커 속 확대 그림이다. 물 알갱이 사이에 흩어진 소금 알갱이(녹은 것)를 그린다.
  - 녹지 않은 소금 덩어리와 모래 알갱이(크고 각진 갈색)를 그린다. 거름종이 구멍 그림에서 모래는 걸리고 녹은 소금은 지나간다.
  - 라벨: "녹은 소금", "녹지 않은 소금", "모래", "거름종이"
  - 그림 아래 문구: "녹은 소금 알갱이는 아주 작아서 거름종이 구멍을 지나가요." 화면 설명이며, 금지 구절과 겹치는지 확인한다.
  - reduced-motion이면 정지한다.
- **그래프**
  - y = solidG, 라벨 `접시 위 가루(g)`, y 0~12 고정(yTicks 0·3·6·9·12)
  - x 라벨 `시간(분)`, xTicks 0·4·…·20
  - markers: 3분 "거르기 시작", 8분 "가열 시작"
- **센서**: "가상 전자저울: 증발 접시"(solidG, 기존 scale kind)
- **결과 열**: 얻은 소금(g), 섞인 모래(g)
- **예측 비교**: metric = salt(sampleKey saltOnDishG), `sameThreshold` = 0.05
- **재생 후 플레이헤드**: `restPlayhead` = 20
