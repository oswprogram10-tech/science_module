# 구현 사양: 3학년 「물체와 물질」 최소 활동 (v0) — 물질의 성질로 물체 분류하기(card-sort groups 재사용)

> 앞 사양: `phase2-roadmap.md`(순서 12), `g3-animal-mvp.md`(card-sort groups). 코드 변경은 최소로 한다. 매니페스트, 아이콘, 등록, 테스트만 추가하는 것이 목표이다.

## 0. 결정

- `card-sort`의 `layout: 'groups'`를 그대로 쓴다. `@sci/cardsort` 로직이나 groups 화면을 바꿔야 하면 바꾸기 전에 보고한다. 단원 전용 분기는 넣지 않는다.
- 카드는 "물체"이고, 관찰 특징은 그 물체를 이루는 "물질의 성질"이다. 카드 이름 아래에 물질 이름을 함께 적는다(예: "쇠못 · 금속").
- 학습 장치
  - 플라스틱 자는 단단하면서 휘어진다. 그래서 "단단한가"와 "휘어지는가"가 같은 분류를 만들지 않는다.
  - 알루미늄 포일은 금속이지만 단단하지 않다. "금속은 다 단단하다"는 오개념을 흔든다.

## 1. 활동 개요

- **탐구 질문**: "물체를 이루는 물질의 성질에 따라 물체를 어떻게 분류할 수 있을까?"
- **카드 8장**(교사 검수 대상)

| 카드(물질) | hard 눌러도 모양이 그대로 | bends 구부리면 휘어짐 | absorbs 물을 빨아들임 |
|---|---|---|---|
| 쇠못(금속) | yes | no | no |
| 유리구슬(유리) | yes | no | no |
| 나무 블록(나무) | yes | no | yes |
| 플라스틱 자(플라스틱) | yes | yes | no |
| 고무줄(고무) | no | yes | no |
| 종이(종이) | no | yes | yes |
| 면 손수건(섬유) | no | yes | yes |
| 알루미늄 포일(금속) | no | yes | no |

- **분류 기준 4가지**
  - hard "손으로 눌러도 모양이 그대로인가요?": 그대로이다 / 모양이 변한다
  - bends "손으로 구부리면 휘어지나요?": 휘어진다 / 휘어지지 않는다
  - absorbs "물을 떨어뜨리면 빨아들이나요?": 빨아들인다 / 빨아들이지 않는다
  - subjective "값비싸 보이나요?": 비싸 보인다 / 싸 보인다 (`objective: false`)
- **관찰 문장**(카드 × 특징)
  - 쇠못
    - hard: "세게 눌러도 모양이 변하지 않아요."
    - bends: "손으로 구부려도 휘어지지 않아요."
    - absorbs: "물방울이 동그랗게 맺혀 있어요."
  - 유리구슬
    - hard: "세게 눌러도 모양이 변하지 않아요."
    - bends: "손으로 구부릴 수 없어요."
    - absorbs: "물방울이 또르르 굴러떨어져요."
  - 나무 블록
    - hard: "세게 눌러도 모양이 변하지 않아요."
    - bends: "손으로 구부려도 휘어지지 않아요."
    - absorbs: "물방울이 천천히 스며들어 그 자리 색이 진해져요."
  - 플라스틱 자
    - hard: "눌러도 모양이 그대로예요."
    - bends: "양 끝을 잡고 구부리면 휘었다가 놓으면 돌아와요."
    - absorbs: "물방울이 맺혀 있고 스며들지 않아요."
  - 고무줄
    - hard: "손가락으로 누르면 쉽게 눌려요."
    - bends: "쉽게 휘어지고 늘어나요."
    - absorbs: "물방울이 맺혀 있고 스며들지 않아요."
  - 종이
    - hard: "손으로 누르면 구겨져요."
    - bends: "쉽게 휘어지고 접혀요."
    - absorbs: "물방울이 금방 스며들어 젖어요."
  - 면 손수건
    - hard: "손으로 누르면 쉽게 모양이 변해요."
    - bends: "쉽게 휘어지고 접혀요."
    - absorbs: "물방울이 금방 스며들어 넓게 퍼져요."
  - 알루미늄 포일
    - hard: "손으로 누르면 쉽게 구겨져요."
    - bends: "쉽게 휘어지고 구부린 모양 그대로 있어요."
    - absorbs: "물방울이 맺혀 있고 스며들지 않아요."
- **용어**: "물체", "물질", "성질"을 쓴다. 밀도·탄성·흡수율 같은 용어는 쓰지 않는다(`limits`).

## 2. 매니페스트 (`content/units/g3-material/manifest.json`)

- 단원 정보: id `g3-material`, title "물체와 물질", grade 3, engine "matter", standards `["4과02-01"]`(추정, 고시 대조 필요)
- 실험 정보
  - experiment id `material-sort`, module `card-sort`, layout `groups`
  - title "물질의 성질에 따라 물체 분류하기", question은 §1
  - features: hard 단단함, bends 휘어짐, absorbs 물 흡수
  - cards: §1 표의 8장. 카드 라벨은 물체 이름이고, 물질 이름은 `sublabel` 필드에 둔다. 스키마에 없으면 선택 필드로 추가한다.
  - icon key: nail, marble, woodblock, ruler, rubberband, paper, handkerchief, foil
- limits: ["밀도", "탄성", "흡수율", "경도", "전성", "연성"]
- 안전: safetyChecklist는 비워 둔다. safetyNotices는 없다.
- tutor.forbiddenAnswers
  - "금속은 단단"
  - "플라스틱 자는 단단하면서 휘어"
  - "알루미늄 포일은 단단하지 않"
  - "종이와 손수건은 물을 빨아들"
  - "나무 블록은 물을 빨아들"
  - "값비싸 보이는가는 분류 기준이 될 수 없"
- tutor.probes: g3-animal과 같은 상황 목록에 같은 원칙으로 쓴다.
  - choose-criterion: "물체들을 어떤 성질로 나누어 볼까요? 누가 나누어도 같은 결과가 나오는 기준을 골라 보세요."
  - pick-card: "어떤 물체부터 살펴볼까요?"
  - before-observe: "{card}을(를) 넣기 전에 '{criterion}'에 맞게 직접 시험해 볼까요?"
  - sorting: "{card}을(를) 시험한 결과를 보고 어느 무리에 넣을지 정해 볼까요? 왜 그렇게 생각했나요?"
  - check-subjective: "'{criterion}'로 나누면 친구와 내 결과가 같을까요? 누가 나누어도 같게 나오는 기준인지 생각해 볼까요?"
  - check-unplaced: "아직 무리에 넣지 않은 물체가 있어요. 모든 물체를 넣어 볼까요?"
  - check-unobserved: "{card}은(는) 아직 시험해 보지 않았어요. 먼저 시험해 볼까요?"
  - check-inconsistent: "{card}을(를) 시험한 결과와 넣은 무리를 다시 비교해 볼까요?"
  - check-complete: "시험한 결과와 분류가 잘 맞아요. 이번에는 다른 성질로도 나누어 볼까요?"
  - finished: "두 가지 성질로 나누어 보았어요. 같은 물질로 만든 물체인데 다른 무리에 들어간 것이 있나요?"
- 돋보기 버튼 문구
  - 이 단원은 "살펴보기" 대신 "시험하기"가 자연스럽다("눌러 보기", "구부려 보기", "물 떨어뜨려 보기").
  - 특징마다 버튼 문구를 매니페스트 `features[].action`(선택 필드)으로 둔다. 없으면 기존 "{label} 살펴보기"를 쓴다.
  - 스키마와 화면에 이 선택 필드를 추가하고, g3-animal의 화면이 바뀌지 않음을 테스트한다.
- 전수 가드: g3-animal과 같은 방식이다. "같은 물질로 만든 물체인데"가 금지 구절에 걸리지 않는지 확인한다.

## 3. 화면

- 아이콘 8개를 단순 SVG로 그린다. 물질감이 드러나게 하고(금속 광택, 유리 투명, 나무 결 등) 다크 모드 대비를 확인한다.
- 시험하기를 누르면 짧은 그림 상태(눌림, 휘어짐, 물방울 스밈)를 카드 상세에 보여 준다.
  - reduced-motion이면 정지 그림만 보여 준다.
  - 그림 상태가 관찰 전에 정답을 드러내면 안 된다. 관찰 전에는 기본 그림만 보인다.

## 4. 검증

- `pnpm typecheck && pnpm test && pnpm build && pnpm e2e`는 모두 종료 코드 0이어야 한다. 기존 기대값은 바꾸지 않는다(단원 수·카드 수 단언만 조정).
- 단위 테스트
  - §1 표 고정
  - `validateCardSortExperiment` 통과
  - 튜터 전수 가드
  - 레지스트리
  - 선택 필드(`sublabel`, `action`) 스키마
  - g3-animal 무변화
- E2E (`e2e/material.spec.ts`)
  - "손으로 눌러도 모양이 그대로인가요?"로 8장을 모두 시험한다. 알루미늄 포일을 "그대로이다"에 넣고 확인하면 "알루미늄 포일은 … 다시 비교해 볼까요?"가 보인다.
  - 고치면 "서로 잘 맞아요"가 보인다.
  - "값비싸 보이나요?"는 "사람마다 다르게"가 보인다.
  - 두 기준을 끝내면 완료 문구가 보인다.
  - 버튼 문구 "구부려 보기"가 보인다.
  - SVG 글자는 13px 이상이다.
  - routing·layout·a11y(밝게·어둡게)에 단원을 추가한다.
- 문서: `docs/testing.md`, README.
