## 0. 결정

- 실험의 기본 대상은 "가상 친구"다. 시뮬레이션 계산과 결과표는 모두 가상 친구 값을 쓴다.
- **실제 학생의 심박 측정(선택 기능)은 아래 조건을 모두 지킬 때만 동작한다**(사용자 결정, 2026-11-05).
  - **H1 허가**: 학생이 동의 화면에서 "허가할게요"를 눌러야 측정 기능이 켜진다. 허가하지 않으면 측정 UI가 잠겨 있다. 동의 화면에는 아래 내용을 쉬운 말로 적는다.
    - 무엇을 재는지
    - 어디에 저장되는지(이 기기 안, 메모리)
    - 언제 지워지는지(앱 종료, 단원 나가기, "지금 지우기")
    - 서버로 보내지 않는다는 것
    - 언제든 그만둘 수 있다는 것
  - 허가는 앱이 켜져 있는 동안만 유효하다. 앱을 다시 켜면 다시 묻는다. 허가 여부도 저장하지 않는다.
  - **H2 기기 안에서만**: 실측값은 React 상태(메모리)에만 둔다. 다음 어디에도 보내거나 쓰지 않는다.
    - localStorage, sessionStorage, IndexedDB, Cache API
    - 교사 대시보드 연결(classroom bus/status)
    - xAPI 기록
    - console 로그
    - URL
    - 실측값을 다루는 코드는 `apps/student/src/modules/exercise-body/realPulse/` 한 곳에 모은다.
  - **H3 자동 삭제**: 앱이 종료되면 메모리와 함께 사라진다. 종료 직전 신호(`pagehide`)에서도 명시적으로 지운다(bfcache로 페이지가 되살아나도 값이 없게). 그 밖에 다음 경우에도 즉시 지운다.
    - 단원 화면을 벗어날 때(컴포넌트 해제)
    - "지금 지우기" 버튼을 누를 때
    - 허가를 거둘 때
    - 마지막 측정 뒤 30분이 지났을 때(앱을 켜 둔 채 잊은 경우)
  - **H4 시뮬레이션과 분리**: 실측값은 시뮬레이션·결과표·예측 비교·튜터 입력에 쓰지 않는다. "내 측정" 칸에만 보여 주고, 가상 친구 값과 나란히 비교할 수 있게 한다.
  - **H5 법무 확인 표시**: 심박은 민감정보이고 만 14세 미만은 법정대리인 동의가 필요할 수 있다. 학교 적용 전 법무 검토가 필요하다고 `docs/app-packaging.md`와 `docs/DEVELOPMENT_PLAN.md` 의사결정 기록(D10)에 적는다.

## 1. 실험 개요

- **탐구 질문**: "운동을 하면 맥박과 호흡은 어떻게 달라질까?"
- **조건 3가지**:
  - 운동 종류: 가만히 앉아 있기 / 걷기 / 제자리 달리기
  - 운동 시간: 1분 / 3분
  - 맥박을 잰 손목: 왼손 / 오른손 — 대조 변인, 영향 없음
- **진행**: 처음 1분 동안 쉬고, 운동한 뒤, 10분이 될 때까지 쉰다.
- **측정**
  - 운동 직후 맥박(회/분)
  - 운동 직후 호흡(회/분)
  - 원래 맥박으로 돌아오는 데 걸린 시간(분)
- **학습 의도**
  - 운동을 하면 몸이 더 많은 산소와 영양소를 필요로 하므로 심장이 빨리 뛰고 숨을 빨리 쉰다.
  - 운동이 셀수록 더 크게 바뀌고, 쉬면 다시 돌아온다. 순환·호흡 기관이 함께 일한다.
  - 손목 방향은 결과를 바꾸지 않는다.
- **용어**: "심장", "혈관", "폐", "맥박", "호흡", "순환 기관", "호흡 기관"을 쓴다. 심박출량·산소 포화도 등은 쓰지 않는다.

## 2. 몸 모델 (`@sci/engine-life`, `body.ts`)

근사 모델이며 **교사 검수 대상**이다. 수치는 초등 고학년의 평균을 단순화했다.

- **입력과 옵션**
  - 입력: `{ kind: 'sit'|'walk'|'run', minutes: number, wrist: 'left'|'right' }`
  - `opts = { totalMin = 10, restBeforeMin = 1, sampleEveryMin = 0.05 }`
- **운동 강도 I**: sit 0, walk 0.35, run 1.0
- **쉴 때 값**: 맥박 85, 호흡 20(회/분)
- **목표 값**: 맥박 `85 + 85·I`, 호흡 `20 + 25·I`
- **시간에 따른 변화**
  - 운동 중(시작 t0 = restBeforeMin, 길이 D): `x(t) = 쉴 때 + (목표 − 쉴 때)(1 − e^(−(t−t0)/0.5))`
  - 운동이 끝난 뒤: 끝 값에서 쉴 때 값으로 시간 상수 1.5분으로 돌아간다.
- **샘플**: `{ t, pulse, breath, effort (0~1: 운동 중이면 I, 아니면 0) }`
- **결과**
  - `pulseEnd`: 운동이 끝난 순간 맥박, 반올림
  - `breathEnd`: 운동이 끝난 순간 호흡, 반올림
  - `recoverMin`: 끝 맥박과 쉴 때 맥박의 차이가 5 이하면 0. 아니면 `1.5·ln(차이/5)`, 소수 첫째 자리
- 손목은 계산에 쓰지 않는다.
- **`validateExerciseExperiment(exp)`**: 세 변인이 있는지, 값이 허용 범위인지 검사한다. 운동 시간 0.5~5분이고, restBeforeMin + 운동 시간 + 5 ≤ totalMin이어야 한다.
- 순수 함수, 난수 없음.

### 2.1 미리 계산한 기준값 (테스트로 고정, 손목 두 가지 모두)

| 운동 | 시간 | 운동 직후 맥박 | 운동 직후 호흡 | 돌아오는 데 걸린 시간(분) |
|---|---|---|---|---|
| 앉아 있기 | 1분 | 85 | 20 | 0.0 |
| 앉아 있기 | 3분 | 85 | 20 | 0.0 |
| 걷기 | 1분 | 111 | 28 | 2.5 |
| 걷기 | 3분 | 115 | 29 | 2.7 |
| 제자리 달리기 | 1분 | 158 | 42 | 4.0 |
| 제자리 달리기 | 3분 | 170 | 45 | 4.2 |

### 2.2 반드시 통과할 테스트

- 표를 손목 두 가지 각각으로 고정한다.
- 손목만 바꾸면 결과가 같다.
- 운동 중 맥박은 단조 증가하고, 끝난 뒤에는 단조 감소한다.
- 10분째 맥박은 쉴 때 값에서 ±15 안에 있다.

## 4. 화면 (`apps/student/src/modules/exercise-body/`)

- **거시(SVG) "눈으로 보기"**
  - 가상 친구 그림(단순한 사람 모양)이 운동 종류에 따른 자세로 있다(앉음, 걷기, 달리기). 운동 중에는 땀방울 표시를 한다. 실제 학생이 아니라는 뜻으로 "가상 친구" 라벨을 붙인다.
  - 손목에 손가락을 댄 모양으로 맥박을 재는 쪽 손목을 표시한다(글자 함께).
  - 상태 띠: "쉬는 중" / "운동 중" / "운동 후 쉬는 중"
  - 아래 문구: `"{분:초} · 맥박 {pulse}회/분 · 호흡 {breath}회/분"`
- **미시 자리(SVG) "몸속 기관 보기"**
  - 심장, 폐, 혈관을 단순화해 그린다(명세서의 "인체 기관 뷰어" 2D판).
  - 심장은 pulse에 맞춰 크기가 뛰고, 혈관을 따라 도는 점의 속도도 pulse에 비례한다. 폐는 breath에 맞춰 부풀었다 줄어든다.
  - reduced-motion이면 움직임을 멈추고 숫자만 보여 준다. 애니메이션은 화면을 떠나면 취소한다.
  - 라벨: "심장", "폐", "혈관". 그림 아래 문구: "심장은 혈액을 온몸으로 보내고, 폐는 숨을 쉬어 공기를 들이마셔요."
- **그래프**: series 두 개를 그린다.
  - 맥박(회/분): 실선
  - 호흡(회/분): 점선
  - y축은 0~180, 라벨 `회/분`이다. x 라벨 `시간(분)`, xTicks 0·2·…·10.
  - markers: 운동 시작 "운동 시작", 운동 끝 "운동 끝". 시행마다 다르므로 함수형 markers를 쓴다.
- **센서**: "가상 맥박계"(pulse, 새 kind `pulse`가 필요하면 추가하고 보고한다).
- **결과 열**: 운동 직후 맥박(회/분), 운동 직후 호흡(회/분), 돌아오는 데 걸린 시간(분).
- **예측 비교**: metric = pulseEnd, `sameThreshold` = 2.
- **재생 후 플레이헤드**: restPlayhead는 운동이 끝난 순간이다(시행마다 다르므로 restPlayhead가 함수를 받도록 일반화한다. 기존 숫자 값도 계속 지원한다).
- **안전**: 처음 실행할 때 점검표를 띄운다. 상시 문구는 모듈 범위 키(`'exercise-body:exercise'`)로 "⚠ 이 화면의 맥박은 가상 친구의 값이에요. 내 맥박은 손목을 짚어 직접 세어 봐요."를 쓴다.

## 4.1 내 맥박 재기 (선택 기능, §0 H1~H5)

화면 위치는 결과표 아래의 "내 맥박 재기(선택)" 접힘 영역이다. 기본은 접혀 있다.

- **동의 화면**: `role="dialog"`. "허가할게요" / "안 할래요" 버튼을 둔다. 문구 예:
  - "내 맥박을 재서 가상 친구와 비교해 볼 수 있어요."
  - "잰 값은 이 기기 안에만 잠깐 두고 서버로 보내지 않아요."
  - "앱을 끄거나 이 단원을 나가면 바로 지워져요."
  - "언제든 그만둘 수 있어요."
- **측정 방법 두 가지**
  1. **손목 맥박 직접 세기**: "15초 재기" 버튼을 누르면 15초 타이머가 돈다. 끝나면 센 횟수를 입력받고 ×4를 해서 회/분으로 기록한다. 입력은 숫자 5~60(15초당)이다.
  2. **블루투스 심박 센서**: 표준 Heart Rate 서비스(`0x180D`), Heart Rate Measurement 특성(`0x2A37`)을 쓴다.
     - `@sci/sensors`의 BLE 프로필에 `heart-rate` 파서를 추가한다. flags의 bit0이 0이면 uint8, 1이면 uint16 little-endian이다.
     - 기존 전송 계층(Web Bluetooth / Capacitor)을 재사용한다.
     - 수신 값은 메모리에만 두고, 화면에는 최근 값과 "센서 연결됨"을 보여 준다.
- **기록 칸**: "운동 전", "운동 직후", "3분 뒤" 세 칸에 내 맥박을 넣을 수 있다. 각 칸 옆에 같은 시점의 가상 친구 값을 보여 준다.
- **버튼**: "지금 지우기", "그만두기"(허가 철회 → 지우기).
- **안내 문구**: "내 맥박은 사람마다 달라요. 가상 친구와 똑같지 않아도 괜찮아요." 비교만 하고 판정하지 않는다.
- **테스트로 보장할 것**(단위 + E2E)
  - 허가 전에는 측정 버튼이 비활성이다.
  - 측정 뒤 localStorage·sessionStorage·IndexedDB에 실측값이 없다. E2E에서 storage 내용을 덤프해 숫자를 찾는다.
  - xAPI 기록과 교사 대시보드로 가는 메시지에 실측값이 없다. 수업 E2E에서 서버가 받은 status에 관련 필드가 없음을 확인하고, recorder를 가로채 확인한다.
  - 단원 목록으로 나갔다 오면 값이 비어 있고 다시 허가를 묻는다.
  - "지금 지우기"와 30분 경과(가짜 시계)로 지워진다.
  - heart-rate 파서(uint8·uint16 flags)가 동작한다.
