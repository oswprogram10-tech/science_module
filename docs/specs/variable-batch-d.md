# 확장 사양: 기존 단원에 새 변인 실험 5개 (교육과정 원문의 빠진 성취기준, 3차 묶음 2)

> 근거: 교사 검토 문서 「새 실험 29개 과정 초안」의 ★ 아닌 항목 가운데 조건을 바꾸는 실험 다섯이다. 선생님 확정 전 초안이고, 모델 수치·문장은 교사 검수 대상이다.
> 본뜰 것: `docs/specs/variable-batch-b.md` 0장의 공통 결정과 그 구현(`sound-vibration`, `lever-lift`, `magnet-poles`, `heat-contact`). 범주형 결과 칸은 `magnet-poles`·`electromagnet`을 따른다.
> 구현은 두 번에 나눈다: D1 = 1·2·3, D2 = 4·5. 묶음마다 전체 검증 체인을 통과시키고 따로 PR로 낸다.

## 0. 공통 결정
- `variable-batch-b.md` 0장을 그대로 따른다(새 모듈, 엔진 패키지의 순수 함수 모델, 예측·한 번에 하나만 바꾸기·결과표·눈으로 보기·그래프·모의 센서, 실행 전 결과 그림 없음, 대조 변인, SVG 글자 13 px 이상, probes 상황 목록, 전수 가드, 시나리오 덧붙이기, 예시 sft 2·pairs 1·redteam 1, 교사 편집 카탈로그 자동 반영, 문서 갱신).
- 예측 문구는 예측 버튼(늘어난다·줄어든다·변하지 않는다)에 맞는 **양**을 묻는다. 실행 전 probe도 같은 양을 쓴다.
- 단원에 활동이 세 개 이상이 되는 곳(g3-force 4개, g3-sound 3개)이 있다. 활동 탭, 교사 앱, 수업 서버, 튜터 편집 카탈로그가 맞게 동작하는지 테스트로 확인한다.
- 선생님이 정할 것(초안 문서의 「정할 것」)은 아래 기본값으로 만든다.

## 1. g3-force 세 번째 활동 `push-pull` (4과01-01) — D1
- 제목: "밀고 당기면 생기는 변화"
- 탐구 질문: "물체를 밀거나 당기면 물체에 어떤 변화가 생길까?"
- 예측: "예측: 물체가 움직인 거리는?"
- 정할 것 기본값: 찰흙을 넣는다. 세기는 두 단계이다.
- 변인
  - `object` "물체": 장난감 수레(`cart`) / 고무공(`ball`) / 찰흙 덩어리(`clay`). 기본 수레.
  - `action` "하는 일": 밀기(`push`) / 당기기(`pull`, 물체에 맨 줄을 당김). 기본 밀기.
  - `strength` "힘의 세기": 약하게 / 세게. 기본 약하게.
  - `color` "물체 색깔"(대조): 빨간색 / 파란색
- 결과
  - `distance` "움직인 거리(cm)": 정수
  - `direction` "움직인 방향"(범주): "손에서 멀어지는 쪽" / "손 쪽으로"
  - `shape` "모양"(범주): "그대로" / "눌려 납작해짐" / "길게 늘어남"
- 모델

  | 물체 | 약하게 | 세게 | 모양 |
  |---|---|---|---|
  | 수레 | 30 cm | 80 cm | 그대로 |
  | 고무공 | 20 cm | 50 cm | 그대로 |
  | 찰흙 | 2 cm | 5 cm | 밀기 → 눌려 납작해짐, 당기기 → 길게 늘어남 |

  - 거리는 밀기와 당기기가 같다. 방향은 밀기 → 손에서 멀어지는 쪽, 당기기 → 손 쪽으로.
- 화면
  - 눈으로 보기: 책상 위 물체와 손. 실행하면 손이 밀거나 줄을 당기고 물체가 움직인다. 찰흙은 모양이 바뀐다. 자 눈금이 바닥에 있다.
  - 그래프: x는 시간(초) 0~2, y는 출발점에서 떨어진 거리(cm) 0~90.
  - 센서: 가상 줄자, cm
- 튜터 iv별 fair-test
  - strength: "힘의 세기만 바꾸었어요. 물체가 움직인 거리는 어떻게 달랐나요?"
  - action: "밀 때와 당길 때 물체가 움직인 방향을 비교해 볼까요?"
  - object: "물체만 바꾸었어요. 물체마다 움직인 거리와 모양은 어떻게 달랐나요?"
  - color: "물체 색깔만 바꾸었을 때 결과가 달라졌나요? 이 결과로 무엇을 알 수 있을까요?"
- finished가 있는 경우 또는 prediction-mismatch: "찰흙과 수레는 힘을 받았을 때 각각 무엇이 변했나요? 결과표에서 찾아볼까요?"
- forbiddenAnswers
  - "세게 밀수록 멀리", "세게 할수록 멀리", "힘이 클수록 멀리", "힘이 셀수록 멀리", "세게 하면 더 멀리"
  - "밀면 멀어지고", "당기면 가까워", "당기면 손 쪽으로"
  - "찰흙은 모양이 변", "힘을 주면 모양이 변", "힘은 모양과 움직임"
  - "색깔은 관계없", "색깔은 상관없", "색깔과 관계없"
- limits: 뉴턴, 가속도, 관성, 마찰력

## 2. g3-force 네 번째 활동 `spring-scale` (4과01-03) — D1
- 제목: "용수철저울로 무게 비교하기"
- 탐구 질문: "무게가 비슷한 물체들의 무게를 어떻게 정확히 비교할 수 있을까?"
- 예측: "예측: 용수철이 늘어난 길이는?"
- 정할 것 기본값: 늘어난 길이(cm)와 저울 눈금(g)을 함께 보여 준다. 비교할 물체는 필통, 가위, 풀, 색연필 묶음.
- 변인
  - `weights` "건 추의 개수": 0개 ~ 5개(추 하나 50 g). 기본 0개.
  - `object` "함께 건 물체": 없음 / 필통(150 g) / 가위(70 g) / 풀(60 g) / 색연필 묶음(90 g). 기본 없음.
  - `springColor` "용수철 색깔"(대조): 노란색 / 초록색 (같은 용수철, 색만 다름)
- 결과
  - `stretch` "용수철이 늘어난 길이(cm)": 소수 한 자리
  - `reading` "저울 눈금(g)": 정수
- 모델: 전체 무게 = 50 × 추 개수 + 물체 무게. 늘어난 길이 = 전체 무게 ÷ 25 (50 g마다 2 cm). 눈금 = 전체 무게.
- 화면
  - 눈으로 보기: 세운 자 옆에 매단 용수철과 고리. 실행하면 추와 물체가 걸리고 용수철이 늘어나 멈춘다. 가위와 풀은 모양이 비슷해 보이도록 크기를 맞춘다(눈으로 무게를 알 수 없게).
  - 그래프: x는 시간(초) 0~2, y는 늘어난 길이(cm) 0~18. 살짝 흔들리다 멈춘다.
  - 센서: 가상 저울 눈금, g
- 튜터 iv별 fair-test
  - weights: "추를 하나 더 걸 때마다 늘어난 길이는 어떻게 변했나요? 결과표에서 규칙을 찾아볼까요?"
  - object: "물체만 바꾸었어요. 눈으로 보기에 비슷했던 두 물체를 저울로 재 보니 어떤가요?"
  - springColor: "용수철 색깔만 바꾸었을 때 결과가 달라졌나요? 이 결과로 무엇을 알 수 있을까요?"
- prediction-mismatch: "저울 눈금이 같으면 두 물체의 무게에 대해 무엇을 말할 수 있을까요? 결과표에서 눈금을 견주어 볼까요?"
- forbiddenAnswers
  - "추가 늘면 늘어난 길이", "추를 하나 더 걸 때마다 2", "추 한 개에 2", "50 g마다 2", "50g마다 2"
  - "무거울수록 많이 늘어", "무거울수록 길게 늘어", "무게가 클수록 많이 늘어"
  - "가위가 풀보다 무거", "풀이 가위보다 가벼", "필통이 가장 무거"
  - "용수철 색은 관계없", "용수철 색깔은 관계없", "색깔은 상관없"
- limits: 뉴턴, 탄성, 훅의 법칙, 질량

## 3. g4-gases 두 번째 활동 `gas-weight` (4과15-01) — D1
- 제목: "공기를 넣은 페트병의 무게"
- 탐구 질문: "공기를 더 넣으면 무게가 어떻게 달라질까?"
- 예측: "예측: 페트병의 무게는?"
- 정할 것 기본값: 누를 때마다 0.025 g 늘어난다(교실 실측값을 주시면 바꾼다). 저울 떨림은 넣지 않는다(같은 조건이면 같은 값).
- 변인
  - `pumps` "공기 주입 마개를 누른 횟수": 0번 / 20번 / 40번 / 60번. 기본 0번.
  - `cap` "마개": 닫아 둠 / 열어서 공기를 뺌. 기본 닫아 둠.
  - `label` "페트병 띠지 색깔"(대조): 빨간색 / 파란색
- 결과
  - `weight` "전자저울 무게(g)": 소수 한 자리
  - `firm` "손으로 눌렀을 때"(범주): "말랑함" / "조금 단단함" / "단단함" / "아주 단단함"
- 모델
  - 처음 무게 45.3 g. 마개를 닫아 두면 무게 = 45.3 + 0.025 × 횟수(0 → 45.3, 20 → 45.8, 40 → 46.3, 60 → 46.8).
  - 마개를 열면 횟수와 상관없이 45.3 g, "말랑함".
  - 단단함: 0번 말랑함, 20번 조금 단단함, 40번 단단함, 60번 아주 단단함.
- 화면
  - 눈으로 보기: 전자저울 위 페트병과 공기 주입 마개. 실행하면 누르는 횟수만큼 손이 누르고, 병이 조금 팽팽해진 뒤 저울 숫자가 바뀐다. 마개를 열면 '쉿' 표시와 함께 병이 처음 모양으로 돌아간다(그림 안에 글자 없음).
  - 그래프: x는 누른 횟수 0~60, y는 무게(g) 45.0~47.0.
  - 센서: 가상 전자저울, g(소수 한 자리)
- 튜터 iv별 fair-test
  - pumps: "누른 횟수만 바꾸었어요. 저울 숫자는 어떻게 달라졌나요? 변화가 아주 작다면 어떻게 확인할 수 있을까요?"
  - cap: "마개를 열었을 때 병의 무게와 단단한 정도는 각각 어떻게 되었나요?"
  - label: "띠지 색깔만 바꾸었을 때 결과가 달라졌나요? 이 결과로 무엇을 알 수 있을까요?"
- prediction-mismatch: "예측과 결과가 달랐네요. 저울 숫자의 소수점 아래 자리까지 견주어 볼까요?"
- forbiddenAnswers
  - "공기도 무게가", "공기는 무게가 있", "기체도 무게가", "기체는 무게가 있"
  - "공기를 넣을수록 무거", "많이 누를수록 무거", "누를수록 무거", "누를수록 무게가"
  - "공기를 빼면 가벼", "마개를 열면 가벼", "마개를 열면 무게가 줄"
  - "띠지 색깔은 관계없", "띠지 색은 관계없", "색깔은 상관없"
- limits: 기압, 밀도, 분자, 압력

## 4. g5-light 두 번째 활동 `light-needed` (6과02-01) — D2

  - object: "물체만 바꾸었어요. 손전등을 끄고도 보인 물체는 무엇이었나요? 그 물체는 어떤 점이 달랐나요?"

## 5. g3-sound 세 번째 활동 `sound-transmit` (4과07-03) — D2
- 제목: "소리가 전달되는 물질과 소음 줄이기"
- 탐구 질문: "소리는 무엇을 통해 전달되고, 어떻게 하면 소리를 줄일 수 있을까?"
- 예측: "예측: 소음계 눈금은?"
- 정할 것 기본값: 전달과 소음 줄이기를 한 활동에 두 변인으로 둔다. 소음계는 dB를 보이지 않고 눈금(0~10)으로만 보인다.
- 변인
  - `medium` "소리를 전하는 것": 공기 / 물 / 책상 나무 / 실 전화기의 실. 기본 공기.
  - `block` "소리 나는 물체를 감싼 것": 없음 / 종이 상자 / 스펀지 / 솜. 기본 없음.
  - `clockColor` "알람 시계 색깔"(대조): 빨간색 / 파란색
  - 소리 내는 물체(알람 시계)와 세기, 거리는 고정한다.
- 결과
  - `level` "소음계 눈금": 0~10 정수
  - `heard` "귀에 들리나요"(범주): "들림" / "들리지 않음"
- 모델
