# 2단계 로드맵: 남은 22개 단원

> 근거: `docs/DEVELOPMENT_PLAN.md` §5(엔진 × 단원 매핑), §7.3(2단계: E3 생명 엔진 구축, 남은 22개 단원).
> 1단계 v0로 10개 단원이 들어갔다. 남은 22개를 아래 순서로 한 단원씩 진행한다. 순서는 단원마다 "사양 → 구현 → 검증 → 커밋"이다.
> 이 표는 **설계 초안**이다. 단원별 사양에서 실험 형태와 수치를 확정하고, 바뀌면 이 표도 고친다.

## 활동 유형

| 유형 | 지금 있음 | 쓰는 단원 |
|---|---|---|
| 변인 실험(variable) | 있음 | 대부분 |
| 지시약 분류(indicator-classify) | 있음 | 산과 염기 |
| 관찰 과제(sky-observation) | 있음 | 지구의 운동, 밤하늘 관찰(재사용 예정) |
| **카드 분류(card-sort)** | **새로 만듦** | 동물의 생활, 식물의 생활, 물체와 물질, 지층과 화석(순서 맞추기 변형). `@sci/cardsort` 공통 로직 |
| **진로 포트폴리오(portfolio)** | **새로 만듦(마지막)** | 과학과 나의 진로. 앞 단원 기록을 모으려고 기기 안 "탐구 기록장"(기본 꺼짐, 결정 D11)을 함께 만듦 |

카드 분류는 일반화한 분류 활동이다. 학생이 기준을 정하고 카드를 무리로 나눈 뒤, 기준과 관찰 특징이 맞는지 확인한다. 산과 염기의 "관찰 근거 기반 확인" 원칙을 그대로 따르고, 이분법 분류 트리와 순서 맞추기를 변형으로 지원한다. 첫 카드 분류 단원(동물의 생활)에서 설계한다.

## 단원마다 공통으로 지킬 것

- 사양에 수치를 미리 계산해 표로 고정한다. 교사 검수 대상으로 표시한다.
- 결과에 영향이 없는 대조 변인을 하나 이상 둔다.
- 결과표 열이 모든 시행에서 같은 값이 되지 않는지 확인한다.
- 튜터 질문 전수 가드 테스트를 둔다. 금지 문장은 질문 문장과 겹치지 않게 쓴다.
- E2E는 단원 흐름, 화면 폭, 접근성(밝게·어둡게)을 확인한다. SVG 글자는 13 px 이상이다.
- 교사 대시보드 상태 보내기와 기기 등급 배율(알갱이류)을 연결한다.
- 성취기준 코드는 명세서 체계로 추정하고 "고시 대조 필요"로 표시한다.
