  - 기록장에 남은 옛 흐르는 물 기록은 unitId가 같아 이 단원 기록으로 보인다. 받아들인다(시행 수 요약뿐이라 해가 없다). 이전 PR의 "옛 unitId 무시" 테스트는 이 결정에 맞게 고친다.
  - 진로 단원 지구와 우주 영역 단원 목록에 `g3-earth-sea`를 다시 넣는다.
- **활동 1 실험** (experiment id `sea-water`, 새 모듈 `sea-water`, 변인 실험, 엔진 `@sci/engine-earth`에 `seaWater.ts`)
  - 제목: "바닷물과 강물 비교하기"
  - 탐구 질문: "바닷물과 강물을 증발시키면 남는 것이 어떻게 다를까?"
  - 예측 문구: "예측: 물을 모두 증발시킨 뒤 접시에 남는 하얀 가루의 양은?"
  - 변인
    - `water` "물의 종류": 강물(`river`) / 바닷물(`sea`), 기본 `river`
    - `volumeMl` "증발 접시에 붓는 물의 양": 50 mL / 100 mL, 기본 50
    - `dish` "증발 접시 모양"(대조 변인, 결과에 영향 없음): 둥근 접시(`round`) / 네모난 접시(`square`), 기본 `round`
  - 종속 변인(결과표)
    - `residue` "남은 하얀 가루(g)": 소수 첫째 자리까지 표시한다.
    - `dryMin` "물이 다 마른 시간(분)": 정수로 표시한다.
  - 모델(교사 검수 대상, 단순화)
    - 바닷물의 소금 등 녹아 있는 것: 질량의 3.5 %. 바닷물 1 mL = 1.025 g이다.
    - 남은 가루 = volume × 1.025 × 0.035
      - 50 mL → 1.79 g, 표시 **1.8**
      - 100 mL → 3.59 g, 표시 **3.6**
    - 강물: 녹아 있는 것이 아주 적다(0.0001 g/mL). 50 mL → 0.005, 100 mL → 0.01이고, 표시는 모두 **0.0**이다.
    - 증발: 알코올램프로 1분에 5 mL씩 줄어든다(물 종류·접시와 무관).
      - 50 mL → 10분, 100 mL → 20분
    - 시뮬레이션 시간은 0~20분이다. 표본 간격은 기존 변인 모듈과 같은 방식을 쓴다.
    - 접시 모양은 어떤 값도 바꾸지 않는다.
    - 화면용 소금 결정 수는 남은 가루 g에 비례한다(0이면 없음).
  - "같다고 보는 기준": 남은 가루 0.1 g
- **화면**(기존 변인 실험 틀)
  - 눈으로 보기
    - 증발 접시, 알코올램프, 남은 물 높이를 그린다.
    - 다 마르면 하얀 가루를 그린다. 바닷물은 하얀 결정이 보이고, 강물은 거의 보이지 않는다.
    - 실행 전에는 결과를 그리지 않는다.
  - 알갱이 보기
    - 물 알갱이와 소금 알갱이를 그린다.
    - 증발하며 물 알갱이만 날아가고 소금 알갱이는 남는다. 범례로 물 알갱이 / 소금 알갱이를 표시한다.
  - 그래프
    - y축: 접시에 남은 물(mL), 0~100 고정(yTicks 0, 25, 50, 75, 100)
    - x축: 시간(분), 0~20(xTicks 0, 5, 10, 15, 20)
    - 선 하나
  - 모의 센서: 가상 전자저울 "접시 위 가루", g, 소수 둘째 자리
  - SVG 글자는 390·1280 px 모두에서 13 px 이상이어야 한다. 겹침과 잘림이 없어야 한다. 다크 모드 대비도 지킨다.
- **안전**
  - 가열 점검표(혼합물 단원과 같은 `heat` 게이트)를 둔다.
    - "보안경을 썼어요."
    - "가열하는 증발 접시는 맨손으로 만지지 않아요."
    - "알코올램프 주변에 종이를 두지 않았어요."
  - 상시 안내: "실험에 쓰는 바닷물은 맛보지 않아요."
- **용어(3학년)**
  - 쓰는 말: "증발", "소금", "하얀 가루", "녹아 있다"
  - 쓰지 않는 말(limits): 염분, 염화 나트륨, 용질, 용매, 농도, 밀도, 퍼밀
- **튜터**
  - probes: 기존 변인 실험과 같은 상황 목록이다(first-trial, repeat, fair-test, confounded, iv-unchanged, prediction-mismatch 등). 모두 질문형으로 쓴다.
  - forbiddenAnswers: 활용형을 포함한다. 최소 목록은 아래와 같다.
    - "바닷물에는 소금이 녹아 있" / "바닷물에는 소금이 들어 있" / "바닷물에 소금이 녹아"
    - "바닷물을 증발시키면 소금이 남" / "바닷물은 하얀 가루가 남"
    - "강물에는 소금이 거의 없" / "강물은 아무것도 남지 않"
    - "물이 많을수록 가루가 많이" / "물을 많이 부을수록"
    - "접시 모양은 관계없" / "접시 모양은 상관없" / "접시 모양은 영향이 없"
  - 전수 가드 테스트로 probe·화면 문구가 금지 구절과 limits에 걸리지 않음을 확인한다.
