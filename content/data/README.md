# 공공 자료

## `kma-seoul-annual-temperature.csv` — 서울 연평균기온 (1907~2025)

- **출처**: 기상청 기상자료개방포털(data.kma.go.kr) → 기후통계분석 → 기온분석
- **검색 조건**: 자료구분 년, 자료형태 기본, 지역/지점 서울(지점 번호 108)
- **이용 조건**: 공공누리 제1유형(출처 표시). 화면에 "출처: 기상청"을 표시한다.
- **받은 날**: 2026-11-10
- **받은 방법**: 포털이 한 번에 30줄씩만 CSV로 내보내서 네 번 나눠 받았다(1907~1936, 1937~1966, 1967~1996, 1997~2025).
  - 원본은 CP949 인코딩이었다. UTF-8로 바꾸고 앞의 검색 조건 줄과 탭을 없앤 뒤, 연도순으로 이어 붙였다.
  - 네 파일의 검색 조건이 모두 "자료구분 : 년", "지역/지점 : 서울"인지 확인했다. 겹치는 해가 없고 빠진 해도 없다.
  - 값은 바꾸지 않았다.

| 열 | 뜻 |
|---|---|
| `year` | 연도 |
| `station` | 지점 번호(108 = 서울) |
| `mean_c` | 평균기온(°C) |
| `mean_min_c` | 평균최저기온(°C) |
| `mean_max_c` | 평균최고기온(°C) |

### 빈 값

- **1907년**: 관측을 10월에 시작해서 연평균이 없다.
- **1950~1953년**: 한국전쟁 때문에 관측 자료가 없다.

### 요약 (검증용, `mean_c` 기준)

- 가장 낮은 해는 1947년 9.6 °C, 가장 높은 해는 2024년 14.9 °C이다.
- 처음 30년(1908~1937) 평균은 10.79 °C, 최근 30년(1996~2025) 평균은 13.09 °C이다.

### 해석 주의

- 서울은 도시가 커지면서 더 따뜻해진 부분(도시 열섬)도 기온 변화에 들어 있다.
- 이 자료만으로 기온이 오른 까닭을 하나로 정할 수 없다. 화면에서는 까닭을 단정하지 않는다.
